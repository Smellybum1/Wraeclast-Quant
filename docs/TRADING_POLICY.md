# Trading Policy

Wraeclast Quant is research software only.

Allowed:

- Market briefs
- Alerts
- Watchlists
- Manual-review recommendations
- Local snapshots

Not allowed:

- In-game buying or selling automation
- Movement, whisper, input, or gameplay automation
- Login-wall, CAPTCHA, access-control, or rate-limit bypasses
- Source usage that violates terms, robots.txt, or API rules

The user must manually execute every trade.
